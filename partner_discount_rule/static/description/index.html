Reglas de Descuento por Cliente

Descuentos automáticos por cliente, etiqueta o categoría, con vigencia por fechas

Definí descuentos (%) para uno o varios clientes — o para una etiqueta de cliente — aplicables a una variante de producto, un producto, una categoría de producto (incluye sus hijas) o todos los productos, dentro de un rango de fechas opcional.

Cómo aplica

  • Al elegir producto en una línea de presupuesto (borrador o enviado), se busca la regla vigente más específica: variante > producto > categoría > global.
  • Ante empate gana la regla de menor secuencia.
  • El cliente matchea directo, por su contacto comercial padre o por etiqueta.

Convivencia con la lista de precios

Cada regla configura cómo combinarse con el descuento que la tarifa ya puso en la columna Descuento:

  • Mayor beneficio al cliente: aplica el mayor de los dos porcentajes.
  • Acumulado: suma ambos porcentajes (tope 100%).
  • Sobreescribir: la regla pisa el descuento de la tarifa.

Configuración

Ventas → Configuración → Reglas de descuento (grupo Administrador de ventas). Cada cliente muestra un botón inteligente con las reglas que le aplican. Activá la opción Descuentos en los ajustes de Ventas para ver la columna.
